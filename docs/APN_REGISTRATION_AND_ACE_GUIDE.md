# AWS Partner Network (APN) Registration & ACE Co-Selling Playbook

**Target Product:** RDS Sentinel (`rds-sentinel`)  
**Audience:** Founders, Business Leads, Cloud Alliances Managers

---

## 1. Step-by-Step APN Registration Checklist

1. **Create APN Partner Account:**
   - Go to [AWS Partner Central](https://partnercentral.awspartner.com/).
   - Sign up using your company domain email (`@cspec.uk` or company domain).
   - Complete company profile details (Companies House registration, tax residency, address).

2. **Unlock APN Select Tier Status:**
   - **Target:** Complete 2 AWS Certified Practitioner or Solutions Architect certifications.
   - **Customer References:** Provide 2 verified customer references or trial case studies.
   - **Annual APN Fee:** $2,500 USD (waived or offset by AWS promotional credits upon qualification).

3. **Pass AWS Foundational Technical Review (FTR):**
   - Execute the in-app **AWS FTR Security Scanner** in `rds-sentinel` Developer Tools dropdown (`runFtrSecurityAudit()`).
   - Confirm 100% compliance across IAM least privilege, edge SQL parameter masking, TLS 1.3, and KMS storage encryption.
   - Submit FTR self-assessment checklist in Partner Central.

4. **Apply for AWS ISV Accelerate Program:**
   - Qualification enables **AWS Sales Co-Selling**: AWS field account reps receive direct sales commission and quota relief when introducing `rds-sentinel` to enterprise accounts.

---

## 2. APN ACE (Customer Engagement) Lead Pipeline Entry

Log every prospective enterprise customer lead in APN ACE Pipeline Manager to connect with assigned AWS Account Managers:

1. Open `rds-sentinel` Developer Tools ➔ **Export APN ACE Pipeline Leads**.
2. Download the pre-formatted `APN_ACE_Opportunity_Pipeline_YYYY-MM-DD.csv` package.
3. Log into AWS Partner Central ➔ **ACE Pipeline Manager** ➔ **Bulk Opportunity Upload**.
4. Upload CSV file to trigger AWS Field Co-Sell alignment.
